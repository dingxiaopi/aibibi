# AI比比字标字体

仅用于 `AI比比` 品牌文字，正文和其余标题继续使用项目原有系统字体栈。

- 原字体：未来荧黑 / Glow Sans SC Normal Bold v0.93，© 2020 Project Wêlai / Celestial Phineas。
- 官方项目：https://github.com/welai/glow-sans
- 官方发行：https://github.com/welai/glow-sans/releases/tag/v0.93 ，`GlowSansSC-Normal-v0.93.zip` 中的 `GlowSansSC-Normal-Bold.otf`。
- 字体授权：SIL Open Font License 1.1，见同目录 `OFL-GlowSans.txt`。上游代码的 MIT 许可证不替代字体的 OFL。
- 本地文件：`ai-bibi-wordmark.woff2`，仅含 A、I、比三个字符。保留原字形，通过 fontTools 将轮廓转为 TrueType 并压缩为 WOFF2；不含完整中文字体。
- 衍生字体使用独立名称 `Bibi Wordmark`，字重 700。本地托管，无需向第三方字体服务发送请求。

确认日期：2026-10-26。
