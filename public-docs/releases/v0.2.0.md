# v0.2.0 · 私有 GitHub Actions 采集

发布日期：2026-11-02。代码采用 MIT，数据与品牌范围仍分别遵循仓库的数据和品牌说明。

## 新增

- 私有状态仓库中的手动采集工作流模板，支持 probe、update、resume、restart。
- AES-256-GCM 加密状态，绑定 sample、hosted、production 身份；认证失败时停止恢复。
- 状态包含来源配置、审核映射、真实采集快照、完整价格观察、检查点和精确续传包；密钥和采集令牌保存在 Secrets。
- 明确选择托管 runner 的来源子集，并可配置专用 runner 标签；公开采集代码固定已审核完整提交。
- 80% 活跃来源成功率门槛、任务串行、失败后保存、汇总日志和私有诊断。
- 新实例配置步骤、凭据生成、常见问题、Issue 表单与 PR 模板。

## 修复

- 排队任务开始执行时读取私有 main 最新状态，避免沿用触发时的旧密文。
- 来源子集同步只处理自身的暂停/排除记录，不误处理其他店铺。
- probe 确认下架并停用监控后，后续 update 保留带原确认时间的下架记录，确保服务器收到下架状态；不刷新原价格观察时间，不重新请求退休商品详情。

## 使用边界

- 采集默认手动，本版本不安装定时任务、不自动批准新商品。
- GitHub 托管 runner 的原店访问能力需实际验证；遇到验证码、登录或 WAF 时不绕过。
- 每位运营者准备自己的来源、分类映射、目标 Worker 和私有状态仓库。仓库不包含原运营实例的店铺清单、真实报价、凭据或加密生产状态。
- 不同 profile 独立保存状态；有重叠来源时需从最新日常状态派生样本，不能用旧副本写回。
- 已有本地采集命令和实例路径保持兼容。仅更新采集工具无需部署 Worker；网站继续使用已有导入协议，无新增数据库迁移。

## 从 v0.1.0 更新

1. 保留自己的忽略目录、实例配置与凭据，检出 v0.2.0。
2. 普通本地更新可继续使用原命令；不使用 Actions 时无需安装加密依赖。
3. 使用 Actions 时，按 [运行说明](../github-actions.md) 建立虚拟环境、密钥和独立私有状态仓库，从少量来源的 probe 开始。
4. 只推送公开源码；保留自己真实的数据时间、审核指纹与已完成批次，不用演示数据替代运营数据。

发布包仅包含公开允许清单内的源码、虚构演示、通用规格和公开文档；SHA256SUMS.txt 用于核对下载文件。

## 发布验收

- 从公开仓库的全新克隆安装锁定依赖，130 项 Python、93 项 Node/Worker 测试通过，TypeScript 检查和构建/部署 dry-run 通过。
- 独立演示数据库迁移和虚构数据初始化通过；浏览器验证本地最低价、演示提示、noindex、无统计脚本及 390px 手机布局。
- 按配置文档初始化新实例，来源占位符保持禁用、映射为空，重复初始化拒绝覆盖原文件。
- 按 Actions 文档生成独立私有密钥，状态准备/恢复逐字节一致，密钥不输出到终端；公开模板保留仅手动触发和固定代码提交的配置。
- 发布包按允许清单生成，排除运行数据、凭据、私有密文、依赖和构建产物；发布后下载附件核验校验和与标签源码。

实际采集链路已另在运营者私有仓库通过采集、推送和服务器回执验收；这不保证其他运营者或所有原店在托管 runner 上可访问。
